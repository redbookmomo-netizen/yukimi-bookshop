# 雪見堂 古書店 · Yukimi-dō Old Bookshop

下雪的夜里，坂道尽头还亮着一盏纸灯笼。推开那扇格子玻璃拉门，风铃响了一声——里面是四千多本旧书。

一个可以在手机和电脑浏览器里漫步的 **3D 第一人称旧书店**。所有东西都打包在一个 `index.html` 里，不依赖任何外部图片、字体、音频或 CDN。

在线打开（GitHub Pages）：<https://redbookmomo-netizen.github.io/yukimi-bookshop/>

## 怎么逛

| 动作 | 手机 | 电脑 |
| --- | --- | --- |
| 推门进店 | 轻触格子门，或点「推门而入」 | 点门 / 回车 |
| 环顾四周 | 手指拖动屏幕 | 按住鼠标拖动 |
| 走动 | 轻点地面；或按住右下角「进 / 退」 | 点地面 / W A S D / 滚轮 |
| 看书 | 远处的书点一下先走过去，**走近后再点**，书会从书架飞到手里翻开 | 同左（鼠标悬停时，够得着的书会亮起来） |
| 翻页 | 点书页右侧下一页，左侧上一页，也可以左右滑动 | 点击 / ← → / 空格 |

- 手机竖屏是单页翻书，横屏或电脑上是左右两页对开。
- 插着红框「店主推荐」卡的 13 本书，走近时头顶会浮出书名；右上角「店主推荐」可以直接带你走过去。
- 其余四千多本普通旧书也都能翻开（随笔、雨的名字、传统色、冬夜星座、季语……），大约一半的书里夹着前一位读者留下的东西：电车票、银杏叶、没寄出的信。
- 柜台上睡着一只黑猫，叫墨丸，可以摸。

## 技术

- [three.js](https://threejs.org/)：书架上的书用 `InstancedMesh` 绘制（每本书独立颜色、尺寸、可单独拾取），推荐书有画在 Canvas 上的竖排书脊和封面。
- 所有纹理（木纹、土壁、和纸、暖帘、招牌、书脊）都由 Canvas 程序生成；插图是内联 SVG 水墨画。
- 走动使用 A\* 寻路 + 拉直路径，绕开书架、平台、柜台和暖炉。
- 翻书器是 DOM + CSS 3D：散文按页面尺寸自动分页，诗歌、俳句、短歌竖排。
- 声音全部由 WebAudio 实时合成：南部铁风铃、木轨拉门、踩雪/木地板脚步、翻页、暖炉噼啪、墨丸的呼噜，以及都节音阶的零星筝音；iOS 静音键下也能出声。

## 本地构建

```bash
npm install
node build.mjs   # 把 src/ 打包成单文件 index.html
```

源码结构：

```
src/
  main.js      相机、输入、寻路、进门动画、拾取与飞书动画
  world.js     场景：街道、店面、书架、书、柜台、猫、暖炉、庭院
  books.js     推荐书全文与普通旧书生成器
  reader.js    翻书器（分页、竖排、封面、扉页、版权页）
  illust.js    水墨 SVG 插图与雪花生成
  textures.js  Canvas 程序纹理
  audio.js     WebAudio 合成音效
  template.html  页面骨架与样式
```
